Go Girls* Timer

For the Go Girls* I wanted a Go clock in a style that fits the event: as cute and girly as the game nights themselves. I also needed one to practise for a tournament. So I built it with Claude Code as my pair programmer, from idea to a first working version in one day. It lies on a phone next to the board, has Fischer and byo-yomi time, statistics with a chart of the time per move, a voice in English and German and several colour themes to switch between, and works offline. It runs in any browser and is now in testing as an Android app on Google Play.

Timebits

Most timers show a number. I wanted to see at a glance how much time is left, and I wanted watching time pass to be a little bit of fun. So in Timebits every minute is a small thing on the screen, like a hedgehog's spike, a duckling or a grain of sand, and it leaves when its minute is over. The items always fill their space, so the picture gets visibly emptier as time passes. You can set minutes, count down to a time or use the Pomodoro technique, in more than 20 looks and 12 colour palettes. I didn't want any settings, only tapping: tap an item and it reacts, tap the background and the whole look changes.

For Timebits I tried a new way of working: a rules file in the repository as a living specification, and a shared task list that several Claude Code sessions work through in parallel. The first version went online on 14 October 2026, and three days later the project had more than 200 commits.
